# Monitor de Ônibus — Rio de Janeiro

Versão estática do protótipo V1, preparada para GitHub Pages.

## O que já funciona

- Pesquisa de linhas
- Seleção da linha
- Exibição do itinerário no mapa
- Paradas
- Ônibus em circulação (dados demonstrativos)
- Seleção de um ônibus para centralizar no mapa
- Atualização automática da interface
- Layout responsivo para celular

## Importante

Esta V1 usa dados demonstrativos. A próxima etapa é conectar os feeds oficiais atuais da SMTR para substituir os dados de exemplo por posições e itinerários reais.

O mapa usa Leaflet e OpenStreetMap.
